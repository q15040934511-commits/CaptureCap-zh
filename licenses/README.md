# 许可证文本目录

本目录保留当前 APK 中发现的第三方许可证材料，并区分 APK 内置文本副本与标准许可证全文。

| 文件 | 内容 | 来源/说明 |
|---|---|---|
| `CaptureCap-APK-MIT.txt` | APK 内嵌 MIT notice | 从 APK 的 `assets/license.txt` 对应仓库副本保留 |
| `COPYING.GPL` | GNU GPL v2 | 与 APK 中同名许可证文本长度相同 |
| `COPYING.LGPL` | GNU LGPL v2.1 | 与 APK 中同名许可证文本长度相同 |
| `COPYING.FDL` | GNU FDL 1.2 | 与 APK 中同名许可证文本长度相同 |
| `COPYING.Xiph` | Xiph BSD 风格许可证 | 与 APK 中同名许可证文本长度相同 |
| `Apache-2.0.txt` | Apache License 2.0 | 标准完整许可证文本；APK 内 AndroidX 包含多个 Apache 2.0 LICENSE.txt 副本 |

根目录 `LICENSE` 保留上游 CaptureCap 当前仓库公布的 MIT 许可证文本。

**重要：** 许可证文本不等于组件映射。请结合 `THIRD_PARTY_NOTICES.md`、完整依赖清单和匹配源码核实每个许可证实际对应的组件和版本。本目录不构成完整 SBOM 或法律意见。
